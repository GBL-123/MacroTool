# ui-dialog-confirmation Specification

## Purpose

让时间线编辑流程中的确认对话框正确呈现标题与正文，并保证显示级标题中的数字以等高字形清晰可读。标题是简短的操作名，正文是解释性长句；数字在标题中不出现高低错落。

## Requirements

### Requirement: 确认对话框的标题与正文各归其位

时间线编辑页中所有需要确认的破坏性或批量操作（修剪、时间缩放、放弃未保存更改并重新载入）在弹出确认对话框时，SHALL 将简短的操作名称作为对话框标题、将解释性长句作为对话框正文，二者不得互换位置。

#### Scenario: 缩放确认对话框

- **WHEN** 用户点击"缩放"并输入了非 1 倍率
- **THEN** 对话框标题为"时间缩放"，正文为以"把全部事件时间缩放为"开头的完整说明句，包含目标倍率与缩放后的总时长

#### Scenario: 修剪确认对话框

- **WHEN** 用户点击"修剪"且保留区间内存在可移除的动作
- **THEN** 对话框标题为"修剪时间线"，正文为说明将移除与保留各多少个动作的完整句子

#### Scenario: 重新载入确认对话框

- **WHEN** 存在未保存更改时用户点击"重新载入"
- **THEN** 对话框标题为"重新载入"，正文为询问是否放弃未保存更改的完整句子

### Requirement: 显示级标题中的数字使用等高字形

对话框标题与页面显示级标题中出现的数字 SHALL 以等高（lining）字形渲染：所有数字高度一致，不得出现 old-style figures 的高低起伏或下沉到基线以下的数字。

#### Scenario: 确认框标题或正文含数值

- **WHEN** 确认对话框的标题或正文渲染包含如"4043"这样的数值
- **THEN** 各数字字形高度一致，其中"0"的视觉高度与其余数字相同，不呈现小写字母 o 的形态

#### Scenario: 显示级标题含数字

- **WHEN** 页面显示级标题（如 page-title、H5/H6 级别标题）包含数字
- **THEN** 数字以等高字形渲染，与标题其余文字基线对齐
