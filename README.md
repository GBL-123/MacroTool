# MacroTool — 浏览器控制面板的 Windows 宏录制器

热键驱动 + 本机浏览器控制面板：按 F10 录一套鼠标/键盘操作，按 F11 无限循环回放；也可以完全在页面里操作，实时查看状态与日志，并在时间线编辑器里清理录制内容。

- 实时录制鼠标左键点击与键盘按键（含按下/抬起节奏、长按时长）
- 录制过程输入**原样透传**，游戏无感知，可边录边玩
- 循环回放整个时间线，支持倍速与点击坐标随机抖动
- 键盘回放带扫描码注入，兼容 DirectInput / Unity / Unreal 系游戏
- 浏览器控制面板（仪表盘 / 运行参数 / 实时日志 / 时间线编辑），只绑定 localhost
- 时间线存为 `timeline.json`，可在编辑器里删除、修剪、平移与缩放，保存时自动留 `.bak`

## 快速开始

```
1. 运行 MacroTool.exe（或开发时 dotnet run --project MacroTool.Web）
2. 浏览器自动打开 http://localhost:5047（可在配置中关闭自动打开）
3. 切到游戏，把鼠标移到要点的位置，按 F10（或页面"开始录制"）
4. 正常操作：点按钮、按技能键……
5. 再按 F10 结束录制（自动保存 timeline.json）
6. 按 F11 开始循环回放，再按 F11 停止
```

> 本工具依赖 Windows 交互式桌面会话与全局热键 / 输入注入，只能在本机运行，不要部署到服务器。

## 控制面板

| 区域 | 作用 |
|------|------|
| 仪表盘 | 状态卡、开始/停止录制与回放、全部停止、实时计数；录制中会醒目提示"不要点击本页面" |
| 运行参数 | 调整倍速、抖动与回放次数；回放中修改**从下一轮生效**，不打断当前轮；次数播完自动停止 |
| 实时日志 | 引擎事件滚动显示（录制、保存、回放轮次、注入失败等），新标签页会带出最近历史 |
| 时间线编辑 | 以动作对为单位清理时间线；仅引擎空闲时可编辑 |
| 关闭服务 | 右上角电源按钮，确认后先关闭面板页面（浏览器拒绝脚本关闭时退化为空白页），再停止录制（必要时先保存）、注销热键并退出进程 |

> 面板由本工具自动打开且未在页面内跳转过时，确认"关闭服务"会直接关闭该标签页；若页面内导航过（或浏览器不支持脚本关闭），则退化为空白页。单标签页场景下进程随即退出，不再等待约 30 秒的连接超时。

## 热键

| 热键 | 功能 |
|------|------|
| F10 | 录制 开始 / 停止 |
| F11 | 回放 开始 / 停止 |
| F12 | 退出进程（若 F12 被其他程序占用，自动降级为 Ctrl+F12；页面会显示实际生效的退出键） |

> F10/F11/F12 注册为全局热键后会被本工具独占，游戏将收不到这三个键。
> 用页面按钮停止录制时，会丢弃最后约 300ms 内的鼠标事件，避免把"点停止按钮"这一下录进时间线；用 F10 停止没有这个过滤。

## 配置

`appsettings.json`：

```json
{
  "Urls": "http://localhost:5047",
  "AllowedHosts": "localhost",
  "Macro": {
    "Speed": 1.0,
    "Jitter": 2,
    "TimelinePath": "",
    "OpenBrowser": true
  }
}
```

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `Macro:Speed` | 1.0 | 启动时的回放倍速初值；运行期以页面参数为准 |
| `Macro:Jitter` | 2 | 启动时的点击抖动（±N 像素）；0 为关闭 |
| `Macro:RepeatCount` | 0 | 回放次数上限；0 = 无限循环，N = 播完 N 轮自动停止 |
| `Macro:TimelinePath` | 空 | 时间线文件路径；留空表示 exe 同目录的 `timeline.json` |
| `Macro:OpenBrowser` | true | 启动后自动打开浏览器（开发配置中默认关闭，避免与 IDE 重复打开） |

> 旧版控制台的 `--speed` / `--jitter` 命令行参数已移除，请改用配置初值 + 页面调参。

## 数据文件

时间线保存在时间线文件路径（默认 exe 同目录 `timeline.json`），启动时自动加载。含事件的录制停止时**整体覆盖**；未捕获任何操作的空录制不会写盘、也不会覆盖既有时间线（日志会说明）。

```json
{
  "recordedAt": "2026-09-14 20:00:00",
  "speedHint": 1.0,
  "durationMs": 1507.4,
  "events": [
    { "t": 387.4, "type": "key",   "vk": 65,  "scan": 30, "ext": false, "up": false, "x": 0,    "y": 0 },
    { "t": 556.8, "type": "key",   "vk": 65,  "scan": 30, "ext": false, "up": true,  "x": 0,    "y": 0 },
    { "t": 735.5, "type": "click", "vk": 0,   "scan": 0,  "ext": false, "up": false, "x": 1920, "y": 1080 },
    { "t": 835.8, "type": "click", "vk": 0,   "scan": 0,  "ext": false, "up": true,  "x": 1920, "y": 1080 }
  ]
}
```

- `t`：相对录制起点的毫秒时间戳；`up`：true=抬起/松开
- `vk`/`scan`/`ext`：虚拟键码、扫描码、扩展键标记（游戏按键识别靠扫描码）
- `x`/`y`：屏幕绝对坐标（仅 click 事件）
- 编辑器保存时会先把上一版备份为 `timeline.json.bak`，再写入新内容

## 时间线编辑器

- **动作对视图**：每行是一次完整操作（点击 / 按键），可展开查看原始 down/up 事件；无法配对的事件标记为"未配对"
- **删除**：删除整对事件；未配对项可单独删除
- **头尾修剪**：按动作**起点**保留 `[开始, 结束]` 区间内的动作，绝不拆开一个动作对；执行前会提示将移除的动作数量
- **平移 / 缩放**：整体或选中动作平移 ±N ms（不会产生负时间）；全部动作按倍率缩放时间；编辑后自动按时间升序重排并重算总时长
- **保存 / 重新载入**：保存写入文件并立即对引擎生效；重新载入会丢弃未保存更改（有确认）
- 仅在引擎空闲时可用；存在未保存更改时，回放仍使用磁盘上的旧时间线

## 构建与发布

```powershell
dotnet build MacroTool.slnx                 # 构建（需 .NET SDK 10.0.400+）
dotnet test MacroTool.slnx                  # 运行单元测试（引擎状态机、编辑器、存储）
dotnet publish MacroTool.Web/MacroTool.Web.csproj -c Release -r win-x64 --self-contained false   # 依赖框架发布
dotnet publish MacroTool.Web/MacroTool.Web.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true   # 自包含单文件
```

## 使用须知与已知限制

- **权限**：若游戏以管理员身份运行，本工具也必须以管理员运行，否则注入会被系统静默拦截（表现为"点了没反应"）
- **窗口位置**：点击坐标是屏幕绝对坐标，录制与回放期间游戏窗口不能移动位置
- **全屏模式**：建议窗口化或无边框窗口；独占全屏下注入可能无效
- **录制时不要点击控制面板**：录制期间页面上的点击会被录入时间线（页面会显示警示）；停止请用 F10，或接受那一下点击被自动过滤的页面按钮
- **仅记录鼠标左键**：右键、中键、滚轮暂不支持
- **反作弊风险**：本工具仅做系统级输入模拟，不注入、不读写游戏进程；但部分反作弊系统仍可能识别并封号，请在单机或允许宏的游戏中使用，风险自担
- **本机限定**：服务只绑定 localhost，不做远程访问与多用户
